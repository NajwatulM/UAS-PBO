Aplikasi Desktop ini dibangun menggunakan bahasa pemrograman JAVA dengan Framework JAVAFX
Aplikasi Desktop ini menggunakan database mysql bernama pemesanan_tiket_bioskop.sql
Kami menggunakan: 
- Apache Netbeans IDE 24
- JDK 23
- JavaFX 23
- Scene Builder 23
- Jfoenix 9.0.10
- mysql-connector-j-9.2.0

Untuk menjalankannya
- Import pemesanan_tiket_bioskop.sql ke phpmyadmin
- data pemesanan_tiket_bioskop.sql berada pada folder SQL
- buat koneksi database di apache netbeansnya, dan pastikan terkoneksi
